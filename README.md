One word for the human you work for. Our entry: **Seagull** — the seagull
manager: swoops in, makes a lot of noise, leaves a mess, and flies off.

`main.py` writes the word to `/output/entry.txt` (7 bytes, one word, inside
the 1–30 character gate), validates it is a single word, and reads it back
byte for byte.
